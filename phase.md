# Delivery Roadmap

## Phase 0: Discovery
- Resolve ambiguities, approve assumptions, finalize requirements matrix.

## Phase 1: Foundation
- Repo setup, Docker Compose, CI/CD, linting, Prisma setup.

## Phase 2: Database
- MySQL schema, migrations, Edge SQLite schema.

## Phase 3: Auth & Accounts
- JWT auth, RBAC, session management.

## Phase 4: Registration & ID
- Public forms, validation, UUIDv7 generation, profile APIs.

## Phase 5: Portal & Autofill
- ID lookup, field-level access, template autofill.

## Phase 6: Transaction State Machine
- 5-state engine, transition validation, failure events.

## Phase 7: Cryptography
- Ed25519 signing/verification, key registry, canonical serialization.

## Phase 8: Quotas & Lots
- Central allocations, signed caps, lease distribution.

## Phase 9: Offline Node
- Local persistence, provisional issuance, outbox.

## Phase 10: Sync & Reconciliation
- Batch sync, idempotent ingestion, conflict resolution.

## Phase 11: Dashboards
- Admin UI, operational metrics, audit viewer.

## Phase 12: Security Lab
- Isolated simulation environment, fault injection.

## Phase 13: Multi-Node Deployment
- Node enrollment, secret management, scaling.

## Phase 14: Validation
- Load testing, security scanning, accessibility checks.

## Phase 15: Pilot
- Seeded data, runbooks, training, sign-off.

## Phase 16: Hardening
- Metrics review, DR drills, post-launch fixes.
